## Project Overview

BW_clock is an Android TV clock application designed for laser projectors. The app displays a black-and-white clock in fullscreen, optimized for always-on projection use.

## Status

This is a new project — no code has been written yet. The plan is to use Jetpack Compose for TV with Kotlin.
